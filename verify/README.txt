Put search-engine verification files here. Every file in this folder (except this README)
is copied to the website root on build, e.g. google1234abcd.html → https://your-domain/google1234abcd.html

  google<code>.html     – Google Search Console (HTML file method)
  BingSiteAuth.xml      – Bing Webmaster Tools
  <your-key>.txt        – IndexNow key file (file name = key, contents = key)
